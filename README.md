# The Ceiling: Why Ruby 4.0 Needed a Second Compiler

Companion repo for the RubyConf 2026 talk. Ruby 4.0 ships two JIT
compilers, YJIT and ZJIT. This repo shows, with real compiler output, how
they differ and why the Ruby core team built the second one.

**Status: draft** (talk on 2026-11-21, captured on Ruby 4.1.0-preview1).
